## 1. Giới thiệu

### 1.1. Mục đích

Tài liệu tổng hợp **toàn bộ error code (API)** và **error message (UI)** của hệ thống, lấy từ các tài liệu:

| Tài liệu nguồn | Phạm vi |
|----------------|---------|
| `Add_Popup_Spec.md` / `Add_Popup_SRS.md` | Tạo skill mới |
| `Detail_Popup_Spec.md` / `Detail_Popup_SRS.md` | Xem chi tiết, rating, comment, download, status, subscription |
| `Edit_Popup_Spec.md` / `Edit_Popup_SRS.md` | Chỉnh sửa skill, xóa file |
| `Skill_Management_Screen_Spec.md` | Màn hình Skill Management (search, delete, export) |
| `Login_User Register before login_SRS.md` | Authentication (login, register, forgot password, OTP, reset) |
| `Settings_SRS.md` / `Settings_Spec.md` | User Settings (profile, preferences, notifications, change password) |
| `User Management Screen_SRS.md` | User Management (search, create, bulk upload, user detail, export) |
| `Home_Screen_SRS.md` | Home Screen & Global Navigation Bar |

Tài liệu phục vụ cho đội phát triển (frontend, backend, QA) làm cơ sở thống nhất xử lý lỗi và kiểm thử.

### 1.2. Định dạng response lỗi API (thống nhất)

```json
{ "success": false, "errorCode": "<ERROR_CODE>", "message": "<error message>" }
```

> Envelope chuẩn `{ success, data }` cho mọi API (prefix path `/api/v1`).

### 1.3. Quy tắc chung

| Quy tắc | Chi tiết |
|---------|----------|
| **Message tiếng Anh** | Mọi error message hiển thị trên UI và trong API response đều dùng **tiếng Anh** |
| **Message có ID** | Mọi message UI được đánh ID `ERR-<MODULE>-NNN` để traceability (frontend map `errorCode` → message ID) |
| 404 thay vì 403 | User ngoài `public_scope` truy cập skill → API trả `SKILL_NOT_FOUND` (404) — không tiết lộ skill tồn tại |
| Anti-enumeration | Login / Forgot Password / Registration không tiết lộ email/account có tồn tại hay không |
| Toast tự ẩn | Toast thông báo tự ẩn sau **3 giây** (NFR-UX-03) |
| Lỗi 500 | Mọi API: "System error. Please try again later." |
| Mất mạng | "Unable to ... Please try again." + giữ nguyên form |

### 1.4. Bảng mã module (ID prefix)

| Prefix | Module |
|--------|--------|
| `ERR-AUTH-` | Authentication (Login / Register / Forgot Password / OTP / Reset) |
| `ERR-SET-` | User Settings |
| `ERR-UM-` | User Management |
| `ERR-HOME-` | Home Screen & GNB |
| `ERR-SM-` | Skill Management Screen |
| `ERR-ADD-` | Add Skill Popup |
| `ERR-DTL-` | Detail Popup |
| `ERR-EDT-` | Edit Skill Popup |

## 2. Error Code — API (Skill AI Management)

### 2.1. Nhóm Skill Name

| Error Code | HTTP | Message | Khi nào xảy ra | API |
|------------|------|---------|----------------|-----|
| `SKILL_NAME_REQUIRED` | 400 | "Skill name is required." | `name` rỗng hoặc chỉ chứa khoảng trắng | `POST /api/v1/skills` · `PUT /api/v1/skills/{id}` |
| `SKILL_NAME_TOO_LONG` | 400 | "Skill name is at most 100 characters." | `name` > 100 ký tự | `POST /api/v1/skills` · `PUT /api/v1/skills/{id}` |
| `SKILL_NAME_DUPLICATE` | 409 | "You already have a skill with this name." | `name` trùng **trong cùng creator** (case-insensitive, soft-delete excluded; khi edit: khác skill hiện tại) | `POST /api/v1/skills` · `PUT /api/v1/skills/{id}` |

### 2.2. Nhóm Public Scope

| Error Code | HTTP | Message | Khi nào xảy ra | API |
|------------|------|---------|----------------|-----|
| `SKILL_INVALID_SCOPE` | 400 | "Invalid public scope." | `publicScope` không thuộc `PRIVATE` / `PART` / `GROUP` / `PUBLIC` | `POST /api/v1/skills` · `PUT /api/v1/skills/{id}` |

### 2.3. Nhóm Description

### 2.4. Nhóm Hashtag

| Error Code | HTTP | Message | Khi nào xảy ra | API |
|------------|------|---------|----------------|-----|

| `SKILL_HASHTAG_TOO_LONG` | 400 | "Hashtag is at most 30 characters." | 1 tag > 30 ký tự | `POST /api/v1/skills` · `PUT /api/v1/skills/{id}` |

## 5. Ghi chú

1. **`SKILL_NOT_APPROVED`** được dùng chung cho 4 hành động (rating, comment, download, subscribe) — message khác nhau theo hành động.
2. **`SKILL_NOT_EDITABLE`** được dùng chung cho 2 tình huống (PENDING_APPROVAL, đã xóa) — message khác nhau theo tình huống.
3. **`INVALID_RATING`** có 3 message tùy lỗi cụ thể (không phải số / ngoài khoảng / không phải bội số 0.5).
4. **`FILE_NOT_FOUND`** có 2 message (download: "Skill file does not exist"; xóa file: "Skill has no file").
5. **Anti-enumeration (auth):** `ERR-AUTH-001` dùng chung cho sai password và user DEACTIVE ở login — không tiết lộ trạng thái tài khoản.
6. **Code trùng tên, message khác theo module:** `EMAIL_REQUIRED`, `INVALID_EMAIL`, `EMAIL_TOO_LONG`, `EMAIL_ALREADY_USED`, `PASSWORD_*` dùng chung code toàn hệ thống (Login SRS, Settings, User Management) — message có thể khác nhẹ theo ngữ cảnh module.
7. Frontend map `errorCode` → message ID theo bảng trên; message luôn hiển thị **tiếng Anh**.
